Overview

MyDatabaseSQL is a fast, focused SQL development tool for SQLite, MySQL, MariaDB and Oracle. It gives you a clean editor, a schema browser and a powerful result grid in a small package that starts in seconds.

If you try it out, feedback is very welcome. Please report bugs and feature requests on the project's GitHub issues page.

-- Example SQL query script
SELECT c.name, COUNT(o.id) AS orders
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
WHERE c.country = 'US'
GROUP BY c.name
ORDER BY orders DESC;

Features

  • SQLite, MySQL, MariaDB and Oracle in one tool
  • Syntax highlighting and auto-completion for each SQL dialect
  • Schema browser for tables, views, columns and indexes
  • Read-only relationship diagram for every schema
  • Sortable, filterable result grid with a per-statement message log
  • Export results to CSV or copy them as INSERT statements
  • Table designer that generates CREATE and ALTER statements
  • Multiple script tabs and movable, dockable panels
  • Code folding, bookmarks and find/replace with regular expressions
  • Query history and saved scripts
  • Auto-save for file-backed scripts
  • Saved sources with device-locked stored passwords
  • Light and dark themes with custom editor font and syntax colours
  • Keyboard shortcuts for common tasks
  • Lightweight with fast startup
  • Cross-platform builds for Windows x64 and Debian-based Linux x64

Builds

Install the version compatible with your operating system. Both builds are 64-bit only.

  • Windows: Windows 10 version 1809 (build 17763) or newer.
  • Linux: a Debian-based distribution with glibc 2.35 or newer — Ubuntu 22.04 LTS, Debian 12 or Linux Mint 21 and newer.
